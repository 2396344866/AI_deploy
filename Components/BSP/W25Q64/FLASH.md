## 一、测试目标与概述

验证 W25Q64（SPI1，CS=PA4，40MHz SCK）**上电自检回环、页/扇区读写一致性、崩溃黑匣子可恢复写入**功能/实时性/鲁棒性达标。黑匣子是看门狗/崩溃取证关键路径，须不依赖 RTOS/DMA 亦可写。

### 1.1 测试环境
| 项 | 内容 |
|----|------|
| 硬件 | STM32H743 + W25Q64（8MB）；SPI1 @ 40MHz |
| 软件 | 固件版本 <tag>；`W25QXX_Test` 上电自检；`w25q_crashlog_save` 黑匣子 |
| 工具链 | Keil MDK ARM v6；ST-Link；逻辑分析仪（SCK/CS 时序） |
| 观测 | `DBG_LOG_FLASH=1` + 串口 `debug4`；Watch `g_flash_state`；读回对比 |

### 1.2 宏配置与代码操作（如何配置宏才能真正生效）

FLASH 自检/黑匣子要出 DEBUG 文本，须先开编译期三道闸。

#### 1.2.1 相关闸门与宏
| 闸门 | 宏 / 手段 | 定义位置 | 作用 | 改后是否需重编 |
|------|-----------|----------|------|----------------|
| 总闸 | `LOG_ENABLED` | `Components/Logger/Inc/logger.h` | 未定义→全部 `((void)0)` 零开销 | 是 |
| Gate3 任务开关 | `DBG_LOG_FLASH` | `dbg_config.h` | 裁 Flash 模块 DEBUG/TRACE 文本（**含 POST 内** `Flash_Test` 的 step 进度细节；属模块开关，**非 POST 框架开关** `DBG_LOG_POSTEST`） | 是 |
| Gate2 运行调级 | `debug<n>` / `logger_set_level()` | `freertos.c:423` | 运行期现场调级 | 否 |
| Gate1 编译上限 | `LOG_COMPILE_MAX_LEVEL` | `Components/Logger/Inc/logger.h` | 决定哪些级别编进 .bin | 是 |

#### 1.2.2 想看 FLASH 自检/黑匣子文本，代码侧必须这样配
1. **开总闸**：`logger.h` 中 `#define LOG_ENABLED`。
2. **开任务开关**：`dbg_config.h` 设 `DBG_LOG_FLASH 1`。
3. **抬编译上限**：`logger.h` 设 `LOG_COMPILE_MAX_LEVEL 4`。
4. **Keil Rebuild**→ Download → Debug。
5. **运行期调级**：串口发 `debug4`（看自检/黑匣子 DEBUG）。

### 1.3 测试数据生成策略
- **正常工况**：随机 256B 页写→读回一致；JEDEC=0xEF4017 校验通过。
- **边界工况**：写满单页（256B）、跨扇区（4096B）边界、地址对齐到页/扇区。
- **异常工况**：写保护位置位、擦除失败返回、SPI DMA 总线错误（拔线）。
- **性能压力**：黑匣子满环连续写（环形覆盖最旧）、长时间高吞吐。
- **抗噪**：40MHz SCK 边沿抖动、VDD 电源纹波、高温。

### 1.4 通过 / 失败判据
- 通过：自检返回 0、写读字节级一致、黑匣子断电后可解析出最近 N 条。
- 失败：回环不一致、自检死循环、黑匣子写后不可读、擦除损坏邻扇区。

### 1.5 总测试步骤（核心步骤前置 · 所有用例共用）

> 下列《》为各用例**共用核心步骤**图例；表格「测试条件·输入」列用 `[宏]/[Keil]/[连]/[发]/[读]` 五要素展开**该用例的具体执行内容**。每次测试前先完整走一遍《编译宏配置》→《Keil 工程操作》→《观测工具连接》，再按用例《命令发送》《观测读取》《判定记录》。
> 五要素：`[宏]`=编译期宏具体值(改后必重编)｜`[Keil]`=工程操作｜`[连]`=观测连接｜`[发]`=测试输入/发送串｜`[读]`=观测与判定点。

- **《编译宏配置》**：按 §1.2.2 设 `LOG_ENABLED`+`DBG_LOG_FLASH=1`+`LOG_COMPILE_MAX_LEVEL=4`。
- **《Keil 工程操作》**：Keil Rebuild(0错误)→Download(F8)→Debug 运行。
- **《观测工具连接》**：逻辑分析仪抓 SPI1（SCK/CS/SDI/SDO）时序；Watch `g_flash_state`；UART1 看 DEBUG。
- **《命令发送》**：上电自检自动跑；性能/异常用例由测试台构造（见各用例[发]）。
- **《观测读取》**：读回字节对比、看 JEDEC、看黑匣子解析、逻辑分析仪时序。
- **《判定记录》**：对比预期，在用例表「实测结果」列填 ✅/⏳/FAIL。

## 四、预期目标（报告量化指标摘要）

### 4.1 功能覆盖指标
- **需求覆盖率**：100%（ReadJedecID/SectorErase/BulkErase/PageWrite/BufferRead/crashlog_save/Test 均有用例）。
- **分支覆盖率**：≥ 90%（写保护/擦除失败/超时分支覆盖）。

### 4.2 性能指标（KPIs）
- **实时性**：单次页写（256B）≤ 5 ms；扇区擦（4096B）≤ 50 ms（40MHz SCK）。
- **精度**：写读回环零字节误差（误码率 0）。

### 4.3 鲁棒性与稳定性
- **长时间稳定性**：连续 72 h 黑匣子写入，Heap/Stack 无增长、无坏块扩散。
- **异常保护**：写保护/总线错均安全返回，崩溃率 0%；黑匣子断电可恢复（崩溃取证闭环）。
