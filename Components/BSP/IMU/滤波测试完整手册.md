## 0. 一句话结论（Verdict）

| 滤波环节 | 机制 | 状态 | 默认 | 运行期开关 |
| --- | --- | --- | --- | --- |
| 物理量·一阶无限脉冲响应低通滤波器（指数移动平均 EMA）| `ImuFilter` LAG | ✅ 已开启 | `α=0.20` | `F lag 1/0 [α]` |
| 物理量·去极值均值 | `ImuFilter` TRIM | ✅ **已开启（默认）** | `win=5` | `F trim 1/0 [win]` |
| 欧拉角·后处理一阶 IIR 低通滤波器 | `attitude` EULER_LAG | ✅ **已开启（默认）** | `α=0.30` | `F elag 1/0 [α]` |
| 姿态解算后端算法 | `Madgwick AHRS`（默认后端）/`ATTITUDE_BACKEND_COMPLEMENTARY` | ✅ 已开启Madgwick | — | 编译期切 |
| 零偏/坏值清洗 | 标定零偏 + 在线零偏 + 饱和剔除 | ✅ 生效 | — | `C` 重标定 |

**核心结论：** 三道滤波（物理量 LAG + 去极值 + 欧拉角后 LAG）现在**全部默认开启**，且都可用串口 `F` 命令在运行期实时开关/调参，**不用重烧固件就能在 VOFA 同屏对比开/关效果**。
```
y[n]=α⋅x[n]+(1−α)⋅y[n−1]
```
**正确调试顺序（本手册立场）：** 先滤波 → 在 VOFA 上确认波形平稳 → 再上 PID 整定。信号带噪时微分项会放大噪声，直接整定 PID 必然震荡，属于本末倒置。

## 1. 滤波在系统里的位置（为什么必须在 PID 之前）

```
MPU6050_ReadRaw(ra,rg)
      │
      ▼
[ImuFilter_Update]  ── 物理量层滤波（imu_filter.c，运行期可配，F lag/trim）
      │   · TRIM 去极值均值      ✅开（默认）  压制单点饱和尖峰
      │   · LAG 一阶滞后低通     ✅开（默认）  压高频抖动
      │   · 输出：raw 计数(保留) + 滤波后物理量 ax/ay/az/gx/gy/gz
      ▼
[Attitude_Update]   ── 姿态融合 + 数据清洗（attitude.c）
      │   · 扣零偏（Init 标定 + 在线 leaky 估计）
      │   · 陀螺饱和坏值剔除（|raw|≥32000 置 0）
      │   · Madgwick AHRS 融合 → s_att_raw（融合直出，未后滤波）
      │   · EULER_LAG 后处理低通 → s_att（最终进控制器的欧拉角） ✅开（默认）
      ▼
[CH30-32 原始欧拉角]  ← 滤波前（s_att_raw）   ┐
[CH27-29 后滤波欧拉角] ← 滤波后（s_att）       ┘ 同屏对比，验证欧拉角后滤波
      │
      ▼
[Attitude_RunController] ── 外环 PID（kp·err + ki·∫err − kd·rate）
      │
      ▼
Motor_SetSpeed → 内环 1kHz 速度 PI → PWM
```

**因果说明：** 滤波是"信号质量"前置工序，PID 是"控制"工序。欧拉角带高频毛刺 → `kd·rate` 与 `err` 把噪声直接灌进 PWM。先滤波把波形压平，再整定 PID，才能区分"是信号脏还是增益错"。

## 2. 当前滤波配置总览（代码事实，非推测）

**`Components/BSP/IMU/Inc/imu_filter.h`（运行期配置，默认值宏）**
```c
#define RAW_FILTER_LAG_DEFAULT    1      /* 一阶滞后默认开 */
#define RAW_FILTER_TRIM_DEFAULT   1      /* 去极值均值默认开 */
#define LAG_ALPHA_DEFAULT         0.20f  /* 物理量层低通系数 */
#define TRIM_WIN_DEFAULT          5      /* 去极值窗口 3~8 */
#define TRIM_WIN_MAX              8
```
- `ImuFilter_Update()`：先去极值均值，再一阶滞后，最后写 `out->ax/ay/az/gx/gy/gz`（滤波后）并保留 `raw_accel/raw_gyro`（未滤波）。
- 运行时配置存在全局 `g_imu_filter`，由 `F lag/trim` 命令动态改，无需重烧。

**`Components/BSP/IMU/Inc/attitude.h`（欧拉角后滤波 / yaw 磁融合默认值宏）**
```c
#define EULER_FILTER_LAG_DEFAULT   1      /* 欧拉角后滤波默认开 */
#define EULER_LAG_ALPHA_DEFAULT    0.30f  /* 欧拉角层低通系数，比物理量层更跟手 */
#define YAW_MAG_GAIN_DEFAULT       0.02f  /* yaw 分离式磁融合增益：陀螺积分 + 磁航向互补 */
```
- `Attitude_Update()`：roll/pitch 由 Madgwick 6 轴融合直出（CH30-32 用 `s_att_raw`）；yaw 额外做 **陀螺积分 + 磁航向低频互补**（仅 yaw，磁由 `s_mag_ready` 门控），写 `s_att_raw.yaw`；再统一经 `s_euler_lpf` 一阶滞后得到 `s_att`（CH27-29 用，进控制器）。
- 运行时用 `F elag`（欧拉角后滤波）、`F yawmag`（yaw 磁融合增益）命令开关/调参。

**数据清洗（非经典滤波，但影响波形）**
- `s_gyro_offset[3]`：Init 阶段静态标定零偏（静置判定：单轴极差 < 5°/s，否则拒绝）。
- `s_gyro_bias_est[3]`：在线 leaky 零偏估计（k=0.002，仅静置代理成立时更新）。
- 陀螺饱和剔除：`|raw|≥32000` 该帧 gyro 置 0，退化为仅加速度求姿态（治尖峰甩到 ±180 的锯齿）。

## 3. VOFA 59 通道与滤波对照表

> 帧宽 `DBG_FRAME_N=59`（索引 0..58），六组：ACC(0–8) / GYRO(9–17) / MAG(18–26) / ATT(27–35) / GBIAS(36–38) / CTRL(39–58)。
> 权威映射见 `Components/Debug/Ref/motor_vofa_telemetry.md` 与 `vofa_panel.json`。raw/flt 已在固件端换算为同单位（accel=g、gyro=°/s、mag=counts），可直接叠放对比；`res=raw−flt` 即滤波抑制量。

| 通道 | 信号 | 滤波状态 | 说明 |
| --- | --- | --- | --- |
| CH0–2 | `raw_accel`(g) | ❌ 原始 | 未滤波加速度（LSB÷16384 已换算，对照基准） |
| CH3–5 | `ax, ay, az`(g) | ✅ TRIM+LAG | 滤波后加速度 |
| CH6–8 | `res_accel`(g) | — | = raw−flt，滤波抑制量 |
| CH9–11 | `raw_gyro`(°/s) | ❌ 原始 | 未滤波角速度（LSB÷131 已换算），看饱和/尖峰在此 |
| CH12–14 | `gx, gy, gz`(°/s) | ✅ TRIM+LAG | 滤波后角速度 |
| CH15–17 | `res_gyro`(°/s) | — | = raw−flt，滤波抑制量 |
| CH18–20 | `raw_mag`(counts) | ❌ 原始 | 未滤波磁力计 |
| CH21–23 | `flt_mag`(counts) | ✅ MTRIM+MLAG | 滤波后磁力计（轴系对齐+硬铁+一阶滞后） |
| CH24–26 | `res_mag`(counts) | — | = raw−flt，滤波抑制量 |
| **CH27** | `roll`（融合后滤波） | ✅ EULER_LAG | **进 PID 的欧拉角** |
| **CH28** | `pitch`（融合后滤波） | ✅ EULER_LAG | 主平衡轴，震荡最直观 |
| **CH29** | `yaw`（融合后滤波） | ✅ EULER_LAG + 磁分离 | 有磁由 CH34 锁定；无磁退化为陀螺积分漂移 |
| CH30–32 | `pre_roll/pitch/yaw` | ❌ 后滤波前 | `s_att_raw`，与 CH27–29 同屏对比 |
| CH33 | `yaw_gyro`(°) | — | 纯陀螺积分 yaw（不碰磁），直观看漂移 |
| CH34 | `mag_hdg`(°) | — | 倾角补偿磁航向（绝对无漂移） |
| CH35 | `yaw_innov`(°) | — | 磁校正前新息 = yaw_wrap_diff(mag_hdg, fused) |
| CH36–38 | `gbias_x/y/z`(°/s) | — | 在线零偏估计，静置应收敛近 0 |
| CH39/41/43 | roll/pitch/yaw `_ref` | — | 参考角（P 命令设） |
| CH40/42/44 | roll/pitch/yaw `_err` | — | = 角 − ref，进 PID |
| CH45–47 | kp/ki/kd | — | 外环增益 |
| CH48–53 | 电机 A/B 速度/PWM/目标 | — | 执行与状态 |
| CH54–58 | 系统（dt/mode/running/steer/hdg_err） | — | 默认关 |

**三套 A/B 对比（运行期即可做，无需重烧）：**
1. **物理量层**：拖 CH0–2 / CH9–11（raw）vs CH3–5 / CH12–14（TRIM+LAG 后）；再叠 CH6–8 / CH15–17（res）看抑制量。开 LAG 正确时，filt 高频毛刺应明显小于 raw、res 不为 0。
2. **欧拉角层**：拖 CH30–32（原始）vs CH27–29（EULER_LAG 后）。开 EULER_LAG 正确时，CH27–29 应比 CH30–32 更平滑。
3. **磁力计层**：拖 CH18–20（raw）vs CH21–23（MTRIM+MLAG 后）；叠 CH24–26（res）。另有 CH33/34/35 三曲线看 yaw 漂移 vs 磁校正 vs 新息。

## 4. 滤波测试四步法（先波形、后 PID）

### 步骤 0：确认滤波已默认编进固件
- 串口日志应有 `attitude outer-loop ready (backend=0 rate=200Hz)`。
- 默认三道全开；发 `F` 或 `F print` 应回显 `raw_lag=1 a=0.20 | trim=1 win=5 | euler_lag=1 a=0.30`。
- 改任何默认值需改 `imu_filter.h`/`attitude.h` 的 `*_DEFAULT` 宏并 **Keil 重编 0 错误**；VOFA 按 **59 通道**重拖控件（旧 37 布局失效）。

### 步骤 1：物理量层 A/B（LAG / TRIM 运行期对比）
1. 静置或手捏晃动，VOFA 同屏拖 CH0–2/CH9–11（raw）与 CH3–5/CH12–14（滤波后）。
2. 判据（默认开）：CH3–5/CH12–14 高频毛刺明显小于 raw；静止时 CH12–14 贴近 0°/s（零偏已扣），无大幅锯齿。
3. **运行期改强度，不重烧：**
   - 想更跟手：`F lag 1 0.35`（α 调大）
   - 想更平滑：`F lag 1 0.12`（α 调小）
   - 关去极值只看 LAG：`F trim 0`；再开：`F trim 1 5`
   - 量化：`α=0.20`@200Hz 截止 ≈ `1/(2π·(dt/α))` ≈ **6.4 Hz**。

### 步骤 2：去极值均值验证（默认已开，确认压尖峰）
- 背景：全量 CSV 分析发现陀螺 ~28% 饱和坏值（单点尖峰）。一阶滞后会被尖峰"带一下"几拍才回稳；去极值均值直接掐掉窗口内极值，对单点冲击更狠。
- 验证：看 CH9–11（raw gyro）里的饱和尖峰，对比 CH12–14（滤波后）是否被削平；前倾/落地冲击瞬间，CH30–32 原始欧拉角有尖峰时，CH27–29 不应被甩飞。
- 窗口：`F trim 1 7` 更平滑更滞后；`F trim 1 3` 更跟手。范围 3~8。

### 步骤 3：欧拉角层 A/B（后滤波运行期对比，重点）
- 仅开感知（不发 `T1`，电机 `running=0` 或 `S` 急停），避免控制反馈干扰。
  - 静置 10s + 缓慢前倾/后仰各一次，VOFA **同屏拖 CH27–29 与 CH30–32**：
  - 默认 `euler_lag=1`：CH27–29 应比 CH30–32 平滑一截，无周期锯齿/高频抖动；
  - 发 `F elag 0` → CH27–29 与 CH30–32 **完全重合**（证明后滤波关闭、无残留）；
  - 发 `F elag 1 0.3` → CH27–29 重新变平滑。
  - 此即"不重烧、运行期 A/B"的验证闭环。

### 步骤 4：确认达标后进 PID
- 滤波达标判据：CH3–5/CH12–14 抖动小、CH27–29 相对 CH30–32 更平滑、前倾无尖峰。
- 达标后按"串级PID测试完整手册"第 4 步上 `T1/R/K` 整定，落地前先写 `K6,0,0.1` 用微分抑振。

## 5. 滤波参数整定速查（默认出厂值）

| 参数 | 位置 | 默认 | 建议范围 | 运行期命令 | 含义 |
| --- | --- | --- | --- | --- | --- |
| 物理量 LAG `α` | imu_filter.h | 0.20 | 0.10~0.40 | `F lag 1 [α]` | 物理量层低通，越大越跟手 |
| 去极值均值 | imu_filter.h | **开**（win=5） | 建议开 | `F trim 1 [win]` | 压单点尖峰 |
| 去极值窗口 | imu_filter.h | 5 | 3~8 | `F trim 1 [win]` | 越大越平滑越滞后 |
| 欧拉角后 LAG `α` | attitude.h | 0.30 | 0.20~0.50 | `F elag 1 [α]` | 欧拉角层低通，比物理量层更跟手 |
| 磁力计 TRIM `win` | attitude.h | **开**（win=5） | 建议开 | `F mtrim 1 [win]` | 磁力计原始计数去极值均值（与物理量 TRIM 对称） |
| 磁力计 LAG `α` | attitude.h | 0.15 | 0.10~0.30 | `F mlag 1 [α]` | 磁力计向量低通，仅影响航向计算 |
| yaw 磁融合 `g` | attitude.h | 0.02 | 0.005~0.05 | `F yawmag [g]` | **仅作用于 yaw**：陀螺积分 + 磁航向低频互补（wrap-safe）；pitch/roll 仍恒由 6 轴融合给出 |
| `ATTITUDE_BACKEND` | attitude.h | MADGWICK | 不变 | — | 融合算法 |
| `COMP_ALPHA` | attitude.h | 0.98 | — | — | 仅互补后端生效 |

**初值推荐（当前已默认落地）：**
```
物理量 LAG     开（α=0.20）
去极值均值     开（win=5）
欧拉角后 LAG   开（α=0.30）
磁力计 TRIM    开（win=5）
磁力计 LAG     开（α=0.15）
yaw 磁融合     开（g=0.02）
```
欧拉角 roll/pitch 恒由 6 轴融合给出（accel 重力参考，不漂）；yaw 在 mag 就绪时用磁航向低频校正锁定，mag 丢失则退化为纯陀螺积分（会漂，由 `s_mag_ready` 自然门控）。先把信号压干净再整定 PID。

## 6. 与 PID 测试的顺序约定（落地流程）

严格按以下顺序，**前一步波形不达标不进下一步**：

```
[滤波测试（本手册）] ──OK──> [感知链验证] ──OK──> [内环速度] ──OK──> [外环极性] ──OK──> [落地 PID 整定]
   波形平稳无尖峰           see 串级PID手册         see 串级PID手册     see 串级PID手册      K 整定（先 kd 抑振）
```

- 滤波达标判据：CH3–5/CH12–14 抖动小、CH27–29 比 CH30–32 平滑、前倾无尖峰。
- 运行期调参用 `F` 命令，确认满意后可把最终值写回 `*_DEFAULT` 宏固定为出厂默认，避免每次上电重设。

## 7. 排错避坑

- **LAG 开了但波形没变？** ①是否真重编链接了 `ImuFilter_Update`；②VOFA 拖的是 CH3–5/CH12–14（滤波后）还是 CH0–2/CH9–11（raw）；③发 `F print` 看 `raw_lag` 是否真为 1。
- **欧拉角后滤波没效果？** 发 `F print` 看 `euler_lag`；VOFA 同屏拖 CH27–29 与 CH30–32：开时两者应不同（CH27–29 更平滑），`F elag 0` 时两者应重合。
- **开了后滤波反而迟钝/滞后？** `α` 太大；调小（`F elag 1 0.2`、物理量 `F lag 1 0.15`）。
- **震荡仍在、滤波已开？** 信号侧已压干净后仍震荡 → 问题在 PID（增益/微分）或机械（轮系间隙、重心高、共振），转"串级PID测试完整手册"第 5 节，不要反复加滤波（过度滤波会吞掉真实运动导致失控）。
- **CH29(yaw)缓漂：** 无磁时退化为纯陀螺积分必然漂（CH33 yaw_gyro 会持续偏离 CH34 mag_hdg），非滤波问题；有磁时由 CH34 磁航向锁定；平衡车不用 yaw 平衡，忽略即可。

## 8. 快速命令清单（VOFA 串口）

| 命令 | 作用 | 备注 |
| --- | --- | --- |
| `F` / `F print` | 打印当前滤波配置 | 回显 LAG/TRIM/EULER_LAG 状态与参数 |
| `F lag 1 [α]` / `F lag 0` | 物理量一阶滞后 开/关 | 例 `F lag 1 0.3` |
| `F trim 1 [win]` / `F trim 0` | 去极值均值 开/关 | 例 `F trim 1 5` |
| `F elag 1 [α]` / `F elag 0` | 欧拉角后滤波 开/关 | 例 `F elag 1 0.3` |
| `P` | 无参打印三轴 ref/err | 确认补偿与当前角 |
| `P<r>,<p>,<y>` | 设三轴参考角 | 如 `P0,-3.6,0` |
| `K<kp>,<ki>,<kd>` | 在线写外环增益 | 必须三数写全 |
| `T1`/`T0` | 开/关外环 | 滤波测试时建议 `T0` |
| `R`/`S` | 启/停内环输出 | 滤波测试时建议 `S` |
| `C` | 静置重标定陀螺零偏 | 板子必须完全不动 |
| `D` | 诊断 MPU6050 寄存器与一次 raw 采样 | 判断 rawG 全 0 是配置问题还是硬件坏 |
