
# 平衡车外环调试与遥测速查指南

**1. 核心控制与遥测架构**

* **硬件接口**：系统使用 **MPU6050**（I2C 地址 `0x68`），通过 **EXTI3** 中断引脚触发 `200 Hz` 传感器任务。
* **数据流向**：系统通过 **UART1** 以默认 **921600** 波特率输出 **VOFA+ FireWater** 格式的 37 通道固定帧。
* **控制链路**：外环姿态控制器计算目标速度，随后由 **1 kHz** 速度内环输出 PWM 驱动电机。

**2. VOFA+ 37 通道映射表**

| 通道编号 | 信号内容 | 说明 |
| --- | --- | --- |
| **CH 0~5** | `raw_accel[0..2]`, `raw_gyro[0..2]` | 原始六轴传感器数据 (LSB)，未滤波，对照基准 |
| **CH 6~11** | `ax, ay, az`, `gx, gy, gz` | 滤波后加速度 (g) 与角速度 (°/s)（TRIM+LAG） |
| **CH 12~14** | `roll, pitch, yaw` | 姿态角 (deg)，**滤波后**；仅 **pitch** 参与平衡；滤波前原始见 CH 34~36 |
| **CH 15~16** | `roll_ref`, `roll_err` | 横滚参考角与误差 (deg) |
| **CH 17~18** | `pitch_ref`, `pitch_err` | 外环目标俯仰角与俯仰误差 (deg)，主平衡轴 |
| **CH 19~20** | `yaw_ref`, `yaw_err` | 偏航参考角与误差 (deg) |
| **CH 21~23** | `kp, ki, kd` | 外环 PID 增益 |
| **CH 24~26** | 电机 A `spd, pwm, target_spd` | 实际速度、输出 PWM、目标速度 |
| **CH 27~29** | 电机 B `spd, pwm, target_spd` | 实际速度、输出 PWM、目标速度 |
| **CH 30~33** | `dt, mode, running, steer` | 循环耗时 (ms)、工作状态与转向分量（系统组，默认关） |
| **CH 34~36** | `raw_roll, raw_pitch, raw_yaw` | 姿态角原始值（**滤波前**，融合直出），与 CH 12~14 同屏对比验证后滤波 |

**3. 串口指令集 (UART1)**

* **`T1` / `T0**`：使能 / 关闭**外环计算**（关闭时自动清除积分项与历史误差）。
* **`R` / `S**`：启动 / 急停**内环输出**（亦可通过板载 **PC13** 按键切换）。
* **`P<roll>,<pitch>,<yaw>`**：设定**三轴参考角（仿 `K<kp>,<ki>,<kd>` 风格，一条命令一次设齐）**，如 `P0,-3.6,0`（pitch 补偿安装偏角）。也支持 `P<deg>` 仅设 pitch（兼容，如 `P-3.6`）。
* **`P`**（无参数）：打印三轴参考角与当前误差，用于确认补偿是否生效。
* **`K<kp>,<ki>,<kd>`**：在线写入**外环 PID 参数**（如 `K5,0,2`）。**必须三数写全**，少写会把其余两值清零；kd 此前有解析 bug 已修（见 error.md E9）。
* **`F` / `F print`**：打印当前**滤波配置**（物理量 LAG / 去极值均值 / 欧拉角后滤波 的状态与参数），确认三道滤波是否出厂默认开启。
* **`F lag 1 [α]` / `F lag 0`**、**`F trim 1 [win]` / `F trim 0`**、**`F elag 1 [α]` / `F elag 0`**：运行期**开关/调参**对应滤波环节，无需重烧即可在 VOFA 同屏 A/B 对比（详见《滤波测试完整手册.md》）。例：`F elag 1 0.3`、`F trim 1 5`、`F print`。
* **`A<val>` / `B<val>**`：单轮**速度开环测试**（仅供内环独立调试使用）。
* **`D`**：诊断 MPU6050，打印 `WHO_AM_I`、`PWR_MGMT_1/2`、`GYRO_CONFIG`、`ACCEL_CONFIG`、`CONFIG` 及一次 `rawA/rawG` 采样，用于区分陀螺零读数是配置问题还是硬件损坏。

**3.1 安装偏角补偿与验证（P 命令）**

IMU 零位与机械"期望姿态"之间常有固定偏角，用参考角补偿：

* 板子放到"期望姿态"（如水平静置想让 pitch 读 0，实测却是 -3.6°），发 `P-3.6` 即可把 pitch_ref 设为 -3.6，使该姿态下 `pitch_err ≈ 0`。
* **验证补偿是否生效（三重确认）**：
  1. 串口发 **`P`**（无参数）→ 打印 `ref(r,p,y)=0.00,-3.60,0.00  err=...`，确认 pitch_ref 已写入且当前误差合理。
  2. VOFA 看 **CH 13 (pitch)** 与 **CH 18 (pitch_err)**：板子处于"期望姿态"时，pitch_err 应≈0；若仍偏离，说明 ref 没设对或板子没在那个姿态。
  3. 改 `P` 值后再发 `P` 无参打印，ref 与 err 应随之变化。
* **注意**：pitch_ref 只补偿"零位偏置"，不改变物理平衡点；真正的平衡点要靠落地实测微调（见第 4 步）。
* roll / yaw：平衡车只用 pitch 平衡，roll_ref/yaw_ref 与 err 主要用于二次开发（如加 roll 稳定环、yaw 航向保持），通过 `P<r>,<p>,<y>` 设定、`P` 无参打印查看。

**4. 串级控制架构**
```
[姿态目标与误差] ---> (外环: 姿态环 PID) ---> [目标轮速 Target_Speed]
                                                  |
                                                  v
[实际轮速反馈] ----> (内环: 速度环 PI) ----> [PWM 占空比] ---> [驱动电机]
```
**内环（速度环）**：直接控制执行机构（电机驱动器与编码器），输入为目标速度，输出为 PWM 占空比。

**外环（姿态环）**：控制系统状态（倾角与角速度），输入为角度偏差，输出为内环的目标速度。

**4. 四步递进验证法**

```
[第 0 步: 传感器感知链] ---> [第 1 步: 内环执行机构] ---> [第 2 步: 悬空双环极性] ---> [第 3 步: 落地物理闭环]
   (MPU6050 软硬件检查)        (电机与速度环验证)          (姿态环符号与响应)            (整定抗扰与直立)

```


**第 1 步：底层感知链验证（传感器存活与极性校验）**。

该检验必须在外环完全关闭（`T0`）**且**电机锁定（`running = 0`）的安全状态下执行，：

* **1.1**：MCU 通过 I2C 读取 MPU6050 内部 `WHO_AM_I` 寄存器（地址 `0x75`）。读取值必须返回固定值 **`0x68`**（AD0 接地）或 **`0x69`**（AD0 接高电平）。串口日志应提示初始化成功，无 `MPU6050 init FAIL` 报错。若报错，需排查 I2C 硬件上拉电阻、设备地址配置及 EXTI 中断引脚连接。


* **1.2**：读取原始加速度计三轴数据（VOFA+ 通道 **CH 0~2** 或滤波后 **CH 6~8**）。
* **判定标准**：
* 车体水平静置时，重力加速度矢量模长应为 $1\text{g}$（原始量程下对应约 $\pm 16384\text{ LSB}$）。
* 重力必须集中在垂直地面的单轴上（如芯片平放时，$a_z \approx +1\text{g}$，$a_x \approx 0$，$a_y \approx 0$）。



* **1.3**：观察姿态解算输出的俯仰角（VOFA+ 通道 **CH 13: pitch**）。
* **判定标准**：
* 车体水平时：$\text{pitch} \approx 0^\circ$。
* 手动向前倾斜：$\text{pitch}$ 应平滑连续增大（或与预期正负极性严格一致），不得出现跳变、过冲或发散。
* 倾斜停止后：角度稳定，陀螺仪通道（**CH 9~11**）角速度在静止时必须回归到 $0^\circ/\text{s}$ 附近（零偏正常）。


在波特率为 921600 时： #define DBG_TELEMETRY_DECIMATE 8  此时实际发送周期：40 ms（对应发送频率为 25 Hz）

$$T_{\text{send}} = T_{\text{base}} \times \text{DBG\_TELEMETRY\_DECIMATE} = 5\text{ ms} \times \text{DBG\_TELEMETRY\_DECIMATE}$$


vofa Δt 填多少，取决于你下位机代码里 发送一帧数据 的周期，不是波特率。
每 10ms 发送一帧数据 → Δt 填 10
每 1ms 发送一帧数据 → Δt 填 1
每 20ms 发送一帧 → Δt 填 20


* **第 2 步：内环速度测试**
* 在单独测试内环速度时，外环必须处于关闭状态（T0）控制指令 A<val> / B<val> 直接向底层速度控制器注入目标值。若此时开启外环（T1），外环任务（200 Hz）会以更高的刷新频率覆盖 A/B 指令写入的值，导致速度设定值发生冲突。
* 保持外环关闭（T0） $\rightarrow$ 开启底层驱动（R） $\rightarrow$ 发送开环/速度指令`A100` 或 `B100`。
* 系统需确认车轮正向平稳旋转，且通道 24/27 读数正确响应。
| **CH 24~26** | 电机 A `spd, pwm, target_spd` | 实际速度、输出 PWM、目标速度 |
| **CH 27~29** | 电机 B `spd, pwm, target_spd` | 实际速度、输出 PWM、目标速度 |

* **第 3 步：悬空外环极性验证**
* 操作者需**同时开启双开关**（先发 `T1` 开启外环，再发 `R` 使能电机）。
* 操作者手持车体向前倾斜，通道 26/29 目标速度必须为**正值**且车轮向前加速。
* 操作者若发现反向暴走，需立即在 `attitude.h` 中反转 **`IMU_PITCH_SIGN`**。


* **第 4 步：落地物理闭环**
* 操作者必须预先配置微分项（例如写入 `K6,0,0.1`），以此抑制高频振荡。
* 操作者手动扶持车辆着地，此时车体应能在轻推下恢复平衡。



**5. 排错避坑重点**

* **车轮死锁不动**：操作者需检查内环 `g_motor_sys.running` 变量；若未发 `R`，内环强制输出零 PWM。
* **无法进入中断**：开发人员需检查 EXTI3 触发配置，并确认 NVIC 中断优先级设为 **6**（必须满足 `≥ configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY`）。
* **指令互相覆盖**：外环开启状态下禁止调用 `A/B` 速度指令，避免双重写入冲突。
