## 2. 9 轴融合方案（MPU6050 + QMC5822L GY273）

### 2.1 新增驱动 `BSP_QMC5822.c/h`（I2C） ✅ 已落地
- GY273 模块 I2C 地址通常为 **0x0D**（QMC5883L），驱动已写死 `QMC_I2C_ADDR=0x0D`，Init 用"读数据非全 0xFF"判在线（不硬判 WHO，兼容批次差异）。
- 初始化序列：RST_PERIOD(0x0A)=0x01 → CTRL2(0x0B)=0x00 → CTRL1(0x09)=0x1D（连续测量/200Hz/2G/OSR512）。
- 量程 ±2G 对应约 12000 counts（标定前仅参考）。
- 已实现接口（非草案）：
  ```c
  int     QMC5822_Init(void);        /* 探测+初始化，失败返回-1（不致命，降级6轴） */
  int     QMC5822_ReadRaw(int16_t mag[3]);  /* 原始 counts（小端） */
  void    QMC5822_DumpStatus(void);  /* 供 M 命令，打印 ready/who/ctrl/raw */
  uint8_t QMC5822_IsReady(void);     /* 1=在线 */
  ```

### 2.2 磁标定（硬铁 + 软铁，椭球拟合）
- 采集：把设备多角度翻滚旋转，收集 raw_mag 点云，拟合椭球 → 求 offset(硬铁) + 变换矩阵(软铁)。
- 落地：标定结果（offset + 3×3 矩阵，约 12 个 float）**存 W25Q64**（见阶段2），上电加载，避免每次手输。
- 调试：标定前后对比就看 **CH40–42（calib_mag）** 是否收成球。

### 2.3 两模块轴系对齐（关键坑，必做）
- MPU6050 与 GY273 是**两块独立小板**，安装朝向大概率不一致。磁力计必须旋转到与 IMU 同一 body 坐标系才能正确参与融合。
- 规划：为每个传感器定义安装旋转矩阵 `R_imu`、`R_mag`（绕轴 0/90/180/270° 或任意姿态），采样后先旋转再融合。
- 验证：设备绕竖直轴转 360°，`mag_heading`(CH43) 应单调 0→360 一圈无跳变；否则旋转矩阵错了。

### 2.4 融合后端选型（两条路线）
**路线 A（推荐先做）：独立倾角补偿罗盘**
- roll/pitch 仍由 MPU6050（Madgwick 6 轴）出；磁航向用经典 tilt-compensated compass：
  ```
  mx2 = mx_c*cos(pitch) + mz_c*sin(pitch)
  my2 = mx_c*sin(roll)*sin(pitch) + my_c*cos(roll) - mz_c*sin(roll)*cos(pitch)
  heading = atan2(-my2, mx2)   // 取负号按安装约定
  ```
- 优点：解耦、好调、天然产生 CH43 与 CH14 的漂移对比；mag 噪声不污染 roll/pitch。
- 缺点：yaw 与 roll/pitch 非联合最优。

**路线 B（升级）：Madgwick MARG 全 9 轴**
- 在 `madgwick.c` 增加 `Madgwick_Update(mx,my,mz, gx,gy,gz, ax,ay,az)`（xioTechnologies 原版自带 MARG 分支），把磁力计直接喂进梯度下降。
- 优点：标准 9 轴 AHRS，yaw 全程可观、无漂移，简历写法更"正规"。
- 缺点：mag 若有软铁残留会拉歪整个姿态，依赖 2.2/2.3 标定与对齐做到位。

> 建议：**阶段1 先 A 跑通验证 GY273 与轴系**，阶段1 末或阶段2 升级到 B。

### 2.5 接入点（数据流）
当前 `freertos.c`：`MPU6050_ReadRaw → ImuFilter_Update → Attitude_Update(Madgwick_UpdateIMU)`。
新增：`QMC5822_ReadRaw → （标定+旋转）→ Attitude_Update` 内部补充 mag 路径，并把 mag 结果经 `Attitude_GetRawMag/GetCalibMag/GetMagHeading` 暴露给遥测。

> **阶段1 当前已落地范围（截至本版）**：仅完成"磁力计数据通路 + 原始 atan2 航向（CH43）"，即磁力计能采集、能在 VOFA 看到、能用 `M` 命令探测。**尚未做**：轴系旋转对齐（§2.3）、倾角补偿罗盘（路线 A）、Madgwick MARG（路线 B）、硬/软铁标定（§2.2）。因此 CH43 目前是原始水平航向，仅作"芯片在线/通信正常"验证；真正"yaw 不漂"需等路线 A/B 落地。yaw 融合仍走 6 轴 `Madgwick_UpdateIMU`（CH14 仍会漂）。

## 5. 风险与未决
- **轴系对齐**是 9 轴成败关键，阶段1 必须先用"绕竖轴转 360° 看 CH43 单调"验证。
- **Madgwick 当前只 6 轴**，阶段1 路线 A 不依赖它改；路线 B 需给 `madgwick.c` 加 MARG 分支（xioTechnologies 原版有，可整体替换）。
- **磁力计怕铁磁**：平衡车电机、螺丝、电池都会引入硬铁，标定必须在"最终安装姿态"下做，拆装后需重标。
- **波特率**：44 通道 @200Hz ≈ 400B/帧，921600 够；若将来 HMI+上云同开，考虑降采样或提到 2M（`DBG_UART_BAUD` 已是宏）。
- **陶晶驰屏 HMI 页面须按实物分辨率/触摸区设计**，勿超出屏幕边界；UART4 已对接，阶段3 可提前启动，与阶段1/2 并行评估。
